# Bavarian Mischief

Marketing site for Bavarian Mischief — game & film studio.

Static site: HTML + CSS + JSX compiled in-browser via Babel Standalone (no build step). Deployed via GitHub Pages at [bavarianmischief.com](https://bavarianmischief.com).

## Local preview

Any static server works, e.g.:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Files

- `index.html` — entry point
- `styles.css` — all styles
- `sections.jsx` — page sections (Nav, Hero, Teem, Films, Studio, Follow, Footer)
- `life.jsx` — supporting components
- `assets/` — logos and imagery
- `CNAME` — custom domain for GitHub Pages
